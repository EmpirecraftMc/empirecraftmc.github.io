## 🌐 Run and host locally
To view or host the website locally, the easiest way is to clone the repository and run a local server.  
1. **Clone the repository:**
```bash
git clone https://github.com/EmpirecraftMc/empirecraftmc.github.io.git && cd empirecraftmc.github.io
```  
2. **Run a local server:**  
- **Using Nginx / Apache:**  
Move the `empirecraftmc.github.io` folder into your web root directory (e.g., `/var/www/` or `/usr/share/nginx/html/`) and update your server configuration to point to it.
- **Using Python**  
Run `python3 -m http.server 8000` inside the folder and open `http://localhost:8000` in your browser.
